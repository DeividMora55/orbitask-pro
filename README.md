# Orbitask Pro - Aplicación Multiplataforma

Aplicación multiplataforma desarrollada como PWA con HTML5, CSS3 y JavaScript.

## Funciones principales
- Dashboard con métricas.
- CRUD completo de tareas.
- Gestión de proyectos.
- Agenda cronológica.
- Módulo de notas.
- Reportes con gráficas en canvas.
- Exportación CSV.
- Respaldo e importación JSON.
- Instalación como PWA.
- Funcionamiento offline con Service Worker.
- Diseño responsivo.
- Paleta negro, rojo y blanco.

## Cómo ejecutarla localmente
Abre una terminal en esta carpeta y ejecuta:

python -m http.server 8080

Luego entra a:
http://localhost:8080

## Publicación
Puedes subir esta carpeta a GitHub Pages, Netlify o Vercel para obtener la URL pública.
